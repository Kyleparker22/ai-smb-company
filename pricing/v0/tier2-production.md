# Tier-2 / Production Employee Pricing — v0 (proposed)

> **Owner: Polo.** Proposals only — **the Founder locks every number.** Pre-revenue: these are *positioning ranges*, not validated prices. Model: `processes/employee-tiers.md`. Shapes: `clients/_yourco-template/employee-patterns-tier2.md`. Tier-1 pricing reference: `pricing/v0/landscaping-hardscaping.md` (~$4k build + $750/mo).

## The pricing principle — value, not cost
YourCo absorbs token/model/infra cost (that never drives the price — `CLAUDE.md`). Tier-2 employees are priced to **a compelling fraction of what the bundle of roles + vendors they replace costs the client.** The pitch writes itself: *one accountable employee, for less than the three vendors it replaces, doing more of the job.*

**Why Tier 2 is priced above Tier 1:** it produces deliverables (copy, campaigns, proposals, reports), replaces multiple line items, and carries a higher reliability + compliance bar.

> ⚠️ **Reconciled to the 2026-06-16 model.** A *single* Tier-2/production employee's one-time fee now lives at the **top of the unified per-employee setup band ($1,000–5,000)** — the old "build $5k–$10k" envelope and the per-shape build figures below (some up to $9k) are **superseded by the $5k cap** for a single employee. Tier-2 *value* is captured in the **retainer** (~$2,000–2,500/mo for a production/compliance single employee, vs. the $1,500 intake anchor) + per-unit options. Anything that would genuinely need more than ~$5k of build is an **AI OS** ($2–5k implementation + $3–10k/mo), not a single employee. The per-shape **retainer** and **per-unit** columns below stand; treat the **build** column as "≤ $5k, toward the top of the setup band."

## How to price a Tier-2 shape (the method)
1. **List what it replaces** — the roles/vendors/tools the client pays for today.
2. **Estimate that bundle's market cost** (monthly + per-unit).
3. **Price the retainer to a clear win** — meaningfully below the bundle, so the ROI is obvious, while well above Tier 1.
4. **Add a per-unit option** where volume drives value (per listing, per vehicle, per proposal) on top of a base retainer.
5. **Build fee** = the design/integration of the pipeline (one-time), scaled by # of connectors + the compliance lift.

# The AI OS bundle — multi-agent "orchestration system" pricing (v0 — the Founder locks)

> When a client buys **several employees as one system**, not a single agent. This is the big-deal shape and the land-and-expand endgame. Owner: **Polo** (proposes); the Founder locks. Shapes: `clients/_yourco-template/employee-patterns-tier2.md` + the agent roster as a template.

## Why the bundle is priced *below* the sum of its agents
The moat — the orchestration, eval, observability, approval, and integration layer — is built **once**. After the first agent, each additional employee rides that shared substrate, so the **marginal cost of agent N is low**. We pass part of that through as a bundle discount, which both wins the deal and deepens lock-in (the more of their business runs on the OS, the higher the switching cost). The pitch: **"a whole department, accountable, for less than two hires."**

## The two entry paths
1. **Land-and-expand (default — Bird's motion, Client Owner's deal).** Start with one agent (Tier-1 or Tier-2). Add agents over time at a **reduced per-agent build + a retainer step-up** — not a new sale each time. The first agent's build can be discounted or waived to land the logo (Client Owner: build waived, retainer + per-agent fees for additions).
2. **System sale.** Client buys the multi-agent orchestration system up front as one bundle (build + one consolidated monthly).

## AI OS pricing (the Founder-locked 2026-06-16 — supersedes the prior bundle table)
The OS is sold as **one system**, not a stack of per-agent build fees:
- **Implementation / onboarding:** **$2,000–5,000 one-time** (consolidated — no separate per-agent build).
- **Retainer:** **$3,000–10,000/mo** consolidated, scaled by system size + vertical (banding in `vertical-ranges.md`).

Deliberately **low implementation + heavy recurring**: lowers the barrier to the flagship and captures value where the moat + lock-in live (the operated, recurring layer). The marginal cost of agent N stays low on the shared substrate, so a flat $2–5k implementation regardless of agent count is margin-safe. The audit credit — **retired 2026-08-16, the Audit is free so there is no fee to credit**; the return prices were ($1,000 Standard / $1,500 Pro) covers **20–50% of implementation** on a 6-month engagement — a strong "just start with the audit" funnel into the OS.

**Graduation rule:** 1–3 employees = à-la-carte individual model ($1k–5k setup each + $1,500/mo +$500 each, cap 3). At the 4th coordinated employee, re-paper as an OS — the value is the coordinated system, not the agent count.

> **Superseded (retired 2026-06-16, kept for history):** the prior per-size build table — Starter (2–3) $6k–10k / $2–3.5k mo · Department (4–6) $8k–15k / $3.5–5k mo · Operating system (7–10) ~$5k–15k / ~$5–7.5k mo. Replaced by the flat-banded implementation fee + the $3–10k retainer above.

- **Consolidated, not additive.** One build engagement + one monthly invoice for the system — explicitly cheaper than pricing each agent à la carte. Show the client both numbers so the discount is visible.
- **Per-agent add-on after the bundle** (Bird's upsell): a reduced incremental build (the substrate already exists) + a retainer step-up. This is the land-and-expand revenue engine.
- **Retainer still covers** maintenance, infra, and token cost across the whole system (YourCo absorbs model spend — `CLAUDE.md`).

## Notes for the lock conversation (the Founder + Polo)
- **Anchor on the headcount + vendor stack replaced**, system-wide: "this system does the work of [N roles] + [M vendors] — that's $X/mo today; the OS is a fraction of it, accountable, one throat to choke."
- **The bundle discount is a feature of the moat, not a giveaway** — marginal agents are genuinely cheap to add on shared infra, so the discount protects margin while winning the deal.
- **Client Owner is the first live test** of the land-and-expand path (build waived → per-agent additions). Use his actual expansion to validate these numbers.
- **Validate before locking** — every figure is pre-data; Polo's quarterly review tightens it against real close-rate + margin.
