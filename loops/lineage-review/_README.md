# loops/lineage-review/

Quarterly artifacts from the lineage review (Brett) — one dated file per run.

Each asks the same question of all 27 agents: **is the expert this agent mirrors still the right one,
and has their thinking moved?** Verdicts are `holds` · `moved` · `replace` · `unverifiable`.

**A run where all 27 hold is a successful run.** The table is the record — a `holds` is a judgement
made, not a check skipped. Proposals only; changing a lineage is the Founder's call.

SOP: `processes/loops/lineage-review.md`
