# AEO/GEO — launch-readiness plan — 2026-06-14

> Mario's first pass. Pre-launch (OtherVenture), so this is the launch-readiness plan + a category baseline, not a live brand audit. Goal: have yourco **citable from day one** instead of starting from zero after launch.

## Citation-presence score
**0%** — by definition. yourco has no public footprint yet (not deployed), so no answer engine can cite it. The score starts moving only once the site is live, indexed, and the interventions below are in place. This run sets the target queries + the build list so the first post-launch run measures real movement.

## Target query set (what we want to be the answer to)
**Category:**
- "done-for-you AI agents / AI implementation for small businesses"
- "how do I add an AI agent to my business without a developer"
- "AI implementation consultancy for SMBs" · "alternatives to building AI agents in-house"

**Per-vertical (lead = landscaping/hardscaping; then roofing, HVAC, plumbing, dental):**
- "AI receptionist / answering service for a landscaping (hardscaping) business"
- "AI to answer after-hours calls for a [vertical]" · "AI intake for a [vertical]"

## The cited set — who's winning today, and why
Audited the category live (WebSearch, 2026-06-14):
- **Category queries** are answered almost entirely from **"best X" roundup listicles** ([warmly.ai](https://www.warmly.ai/p/blog/ai-agents-for-small-businesses), [lindy.ai](https://www.lindy.ai/blog/best-ai-agents-small-business), [siit.io](https://www.siit.io/blog/best-ai-agent-platforms-small-business), [manus.im](https://manus.im/blog/best-ai-agents-for-small-business)) and the **G2 directory** ([G2 AI agents for small business](https://www.g2.com/categories/ai-agents-for-business-operations/small-business)). The brands they cite are **DIY tools/platforms** — Lindy, Synthflow, Tidio, Siit, Helply, Sierra, Ada.
- **Vertical queries** are answered from **vendor per-vertical landing pages** — [AgentZap](https://agentzap.ai/industries/landscaping), [Smith.ai](https://smith.ai/industries/landscape-garden-answering-service), [Allo](https://www.withallo.com/answering-service/answering-service-for-landscaping), [Welco](https://welco.ai/industries/ai-receptionist-for-landscapers/), [Local Call AI](https://getlocalcall.com/landscaping), [ElevenLabs](https://elevenlabs.io/ai-answering-service/landscaping). Every one of them has a dedicated `/industries/<vertical>` page. That's the pattern that gets cited.

**Why this matters (the opening):** the cited set is **DIY tools** and **point voice-receptionists**. "Done-for-you, *operated*, eval-gated AI employees" — yourco's exact category — is barely represented in any answer. The engines don't have a good entity to cite for "I don't want a tool, I want someone to build and run it." yourco can own that phrasing.

## Citation sources map (where the answers get pulled from)
1. **Roundup / "best X" listicles** — the dominant source for category queries. Getting *included* in these is the highest-leverage off-site move.
2. **Review directories** — G2 (seen live), plus Clutch / Capterra. A listing is table stakes.
3. **Vendor per-vertical landing pages** — the dominant source for vertical queries. yourco controls these.
4. **Reddit** — r/smallbusiness, r/landscaping, r/msp (known LLM source; not surfaced in these two queries but pull it monthly).
5. **YouTube** — Reed's demos; increasingly cited.

## Interventions, by leverage (have these LIVE at launch)
1. **Per-vertical landing pages (→ Webb) — highest leverage.** Every cited vertical competitor has `/industries/<vertical>`. Build yourco's per-vertical pages (landscaping/hardscaping first, matching the locked pricing + the demos) with the question phrased as a header and answered directly. This is the single most copyable, highest-ROI technical move.
2. **Schema (→ Webb).** Organization, Service, FAQ, Product markup on the site so engines parse yourco cleanly and build a correct entity. FAQ schema on the answer pages especially.
3. **Direct-answer + "done-for-you vs DIY tool" content (→ Katie).** Pages that answer the category queries head-on, leading with yourco's wedge: *you don't want a tool you have to run, you want an employee that's built and operated for you.* This is the gap in the cited set — name it and own it.
4. **Off-site presence (→ the Founder + Katie).** A Clutch/G2 listing; pitch to be included in the "best AI implementation / done-for-you AI agent for SMBs" roundups (they refresh constantly and link out); helpful, non-spammy Reddit answers in the verticals.
5. **Consistent entity footprint (→ Webb + Katie).** Same one-line definition of who yourco is across the site, LinkedIn, and every directory — anchored on "done-for-you, operated AI employees for [verticals]."

## Handoffs
- **Webb:** per-vertical pages + schema (do these first — they're owned and highest-leverage).
- **Katie:** the direct-answer + comparison content, in yourco's voice (`brand/writing-rules.md`).
- **the Founder:** the directory listings (Clutch/G2) and the roundup-inclusion outreach (these need a human + a live site).
- **Gated on launch:** none of this gets *cited* until yourco is live and indexed — but it should all be *built and staged* now so day-one is citable.

## What I'd watch first post-launch
The vertical queries (landscaping/hardscaping) — narrower, less crowded, and where yourco has the proof (Sample Client). Easier to enter the cited set there than on the broad "best AI agents for small business" query.
