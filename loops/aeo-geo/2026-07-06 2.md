## The cited set — who's winning today, and why (WebSearch, 2026-07-06)

**New this run: the category splits into two cited-sets, and yourco lives in the second one.**

1. **DIY-tools listicles** (unchanged from last run) — "best AI agents for small business" still resolves to roundups (Lindy, warmly.ai, manus.im, heyy.io, Forbes) citing self-serve tools (Lindy, Synthflow, Tidio, Sierra, Ada). This is *not* yourco's category; don't chase it head-on.

2. **Done-for-you agency / "AI OS" cited-set — NEW and directly yourco's lane.** The query "AI automation agency / AI implementation consultancy for small business" now returns a distinct roundup family — DesignRush, Eliya, **NextAutomation**, **Octopus Builds**, **Cohevo**, FirstMoversAI, theaiconsultingnetwork, Xcelacore, MQLFlow, Vstorm (Medium "Top 10 Applied AI Consulting firms for SMBs"). **Why they're cited:** each has (a) a **named, productized package** ("60-day Business OS Setup," "14-day deployment," "Map → Design → Build → Train"), (b) an **explicit phase process** on the page, and (c) **named deliverables**. The engines cite them because the page *directly answers* "what do I get and in what order."
   - **The wedge is narrowing.** Octopus Builds now sells "architect, deploy, and **operate** AI automation... **running in production**, connected to CRM, compliant with policies." Cohevo literally sells a "**Business OS**." "Operated, done-for-you" — the exact phrasing last run said was unclaimed — is being claimed. **yourco's defensible wording must move one layer deeper: not "operated" but "eval-gated, approval-flow, reliability-proven" — the moat layer these agencies still don't name.** That's the differentiation the answer engines don't yet have a good entity for.

3. **Per-vertical receptionist pages** (unchanged pattern, more crowded) — vertical queries still resolve to vendor `/industries/<vertical>` pages, but the field roughly doubled: landscaping now cites AgentZap, Smith.ai, Marlie, Rossy, Greet, Upfirst, myaifrontdesk, ElevenLabs — **and Jobber** (`getjobber.com/features/ai-receptionist`).    - **Two competitive threats worth naming:**
     - **Jobber sells an AI Receptionist**, bundled into the field-service software the landscaping/home-services ICP *already runs*. A point receptionist is now one toggle away for our buyer. yourco's counter is *not* to out-receptionist them — it's to sell the whole operated OS (Sample Client = Aspire-signed → deposit/supplier/sub drafts, approval-gated), the thing a bundled receptionist toggle can't be.

## Interventions, by leverage (build + stage now, cite at launch)

1. **Own the moat-layer wording on the category answer page (→ Katie) — highest leverage, and newly urgent.** "Operated / done-for-you" is being claimed by Octopus Builds, Cohevo, et al. yourco's page must answer "AI implementation consultancy / done-for-you AI agents for small business" by leading with the layer they *don't* name: eval gates, approval flow, watchdogs, a reliability standard you can see pass — plus the audit-first motion. Concrete proof beats adjectives (Sample Client's approval-gated deposit drafts). Follow `brand/writing-rules.md`; per `learnings/content/2026-06-11`, any stat carries a source or is illustrative. **Expected lift:** gives the engines the entity to cite for "I want it built *and held to a standard*, not just handed over."

2. **Per-vertical landing pages + get into the vertical roundups (→ Webb builds, the Founder/Katie pitch) — highest structural leverage.** Every cited vertical competitor has `/industries/<vertical>` with the question as H1, a direct answer, and the software-integration list (Jobber/Aspire/LMN). Build yourco's, landscaping/hardscaping first. *New:* once live, pitch for inclusion in the per-vertical roundups (gettinylawn, Allo-style). **Expected lift:** vertical queries are narrower and where yourco has proof (Sample Client) — the realistic first place to enter a cited set.

3. **Schema (→ Webb).** Organization, Service, FAQ, Product markup so engines build a correct entity. FAQ schema on every answer page. Add a clear, repeated one-line entity definition (below) the crawlers can bind to. **Expected lift:** makes yourco parseable as a distinct entity vs. the tool-vendors.

4. **Get listed in the agency/consultancy roundups (→ the Founder) — the biggest new off-site move.** The DesignRush / NextAutomation / theaiconsultingnetwork / Vstorm family is yourco's actual cited-set and it refreshes constantly. Pitch inclusion once the site is live. Needs a human + a live URL, so it's launch-gated, but line up the targets now.

5. **Directory listings (→ the Founder).** G2 + Clutch + Capterra. Table stakes; a listing is a citable source by itself.

6. **The "done-for-you vs. DIY AI tool" comparison answer (→ Katie).** One page that intercepts buyers arriving from the DIY-tool listicles: *you don't want a tool you have to run and eval yourself — you want an employee that's built, operated, and proven for you.* Directly answers "alternatives to building AI agents in-house." **Expected lift:** converts the wrong-lane traffic into the right-lane entity.

7. **Consistent entity footprint (→ Webb + Katie).** Same one-liner across site, LinkedIn, and every directory. Proposed canonical line for the crawlers: *"yourco is a done-for-you AI implementation consultancy: it audits your business, then builds and operates a custom multi-agent AI OS — eval-gated, approval-flow, held to a reliability standard. You get the outcome; you never touch tokens, models, or infrastructure."*
