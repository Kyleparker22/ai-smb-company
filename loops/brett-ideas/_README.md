# Brett's weekly ideas drop — output log

One dated artifact per Friday run (`<YYYY-MM-DD>_ideas.md`): 3 fresh, ship-able YourCo ideas generated through Brett's four idea-lenses (Levels / Graham / Thiel / Balaji) and rated for focus (Now / Next / Later / Park). SOP: `processes/loops/brett-ideas.md`. Runtime: `runtime/prompts/brett-ideas.md` + `yourco-brett-ideas` timer (Fri 08:00 ET). Also posted to `#yourco-brett`.

The drop is the **top of the idea funnel**, not a decision. An adopted idea graduates to a `decisions/` doc on the Founder's call. Brett revisits a prior idea ("kill or keep") each week so the log compounds instead of sprawling.
