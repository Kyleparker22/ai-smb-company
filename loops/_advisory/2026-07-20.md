# Advisory panel — 2026-07-20 (baseline: the founding runs)

**Scope:** full-company review, run twice in one Cowork session — Panel A (AI minds) + Panel B
(sales/business minds). This artifact is the condensed baseline every future run diffs against
(skill: `.claude/skills/advisory-panel/`). Company state at run time: pre-revenue · Sample Client at
proposal, stalled (~3 weeks, $0 kickoff + $1,000/mo brotherhood pricing) · launch gate closed ·
Sample Product partnership unpapered · ~20 loops + 26 wired agents live on the runtime.

## Convergences (the product)

**C1 — The moat thesis holds from every worldview.** Scaling-believers, LLM-skeptics, and operators
all independently land on reliability/eval/approval/trust as the durable layer (Sutton, LeCun,
Chollet arrive from opposed premises; Buffett/Thiel from moat economics). Core bet validated;
nobody said "build models."

**C2 — Pipeline of one (unanimous, Panel B; loudest overall finding).** The GTM machine is built
(Reilly/Michelle = a textbook Predictable-Revenue org) but the funnel is empty *by choice* — the
launch gate has become a prospecting embargo. Blount/Ross/Graham/Cuban all note the warm-network
pass needs no public launch. **Action-shaped.**

**C3 — The $0 kickoff contradicts audit-first (Enns, Baker, Hormozi, Buffett).** "Paid diagnostic"
is the strategy doc; deal #1 shipped with a free one — a positioning contradiction, not a discount.
Rule going forward: every deal opens with a paid audit; re-anchor Sample Client at first expansion.

**C4 — Take control of the stalled deal (Voss, Challenger, Rackham).** No deadline, no quantified
cost of waiting, no constructive tension. Concrete tools handed over: the Voss no-oriented nudge
("Have you given up on getting proposal turnaround fixed this season?") + an expiring proposal +
payoff questions that make Client Owner state the dollar value himself. **Action-shaped, this-week.**

**C5 — Scaffolding rot is the top technical risk (Sutton, Karpathy, Shazeer).** The model-upgrade
dividend also obsoletes yourco's own pipelines. Proposed: a recurring **scaffold audit** — delete
every chain/router/workaround the newest model now does natively.

**C6 — The autonomy streak rule needs a novelty axis (Chollet, Bengio, Willison).** Streaks measure
the routine case; novel/out-of-distribution-exposed action classes should never fully promote
regardless of streak. Candidate edit to `runtime/autonomy-matrix.md`.

**C7 — Convert internal rigor into trust collateral (Hassabis, Amodei, Willison, Godin).** Three
near-zero-cost moves: client-visible eval reports · a signed per-client "constitution" (what the OS
must never do) · publish the security model + the build-in-public story (the solo-founder-with-AI-
workforce narrative is an unspent purple cow).

**C8 — The moat-backed guarantee (Hormozi × the eval layer).** The one genuinely new offer idea:
yourco can guarantee outcomes ("saves N hours in 60 days or you don't pay") *because* the eval
layer measures them — structurally uncopyable by no-code competitors.

**C9 — Focus: bullets before cannonballs (Collins, Graham, Horowitz, Ng).** Care, Conduit, Storm
Verified = three cannonballs pre-first-signature. Keep parked/paper-only until engagement #1 proves
calibration. (Storm papering = cleanup, not expansion — proceed.)
