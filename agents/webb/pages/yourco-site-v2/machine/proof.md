## Every claim, and the check behind it.

A marketing page is normally a frozen sentence: true when somebody typed it, and there whether or not it stayed true. Ours aren’t. Each claim below is wired to a check that runs on its own schedule. If the check stops passing — or just stops running — the number is withheld and this page tells you which one went quiet.
