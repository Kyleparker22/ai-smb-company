## Per-platform steps (the Founder executes, in order)

**LinkedIn** — Company Page (not a personal profile). Create at linkedin.com/company/setup. Needs the Founder's personal LinkedIn as admin. Set URL slug `yourco`, upload logo + banner, paste the long bio, add website + "Consulting / AI." *Highest priority — this is where the content loop's LinkedIn drafts + carousels land.*

**Instagram** — Sign up in-app or web, username per handle rule, switch to a **Business/Professional account** (Settings → Account type), category "Business Service," add website + email, upload avatar. Enable 2FA immediately.

**TikTok** — Sign up with founder@yourco.example.com, set username, switch to **Business account** (Settings → Account → Switch to Business), category "Education" or "Consulting," add website + bio, avatar.

**YouTube** — Create a **Brand Account channel** (not the personal one) at youtube.com → Settings → Add/manage channel → Create channel → **use a Brand Account** so it's not tied to the Founder's personal identity and can have multiple managers. Name "yourco," upload avatar + channel banner, paste description, set links.

**Meta** — This is two things: (1) a **Facebook Page** for yourco (facebook.com/pages/create → Business/Brand → name "yourco" → category "Consulting Agency" → avatar + cover + bio), and (2) a **Meta Business Suite / Business Manager** (business.facebook.com) that owns the FB Page *and* the Instagram Business account — link IG to the Page here so both post from one place. Do the Page first, then claim both assets inside Business Suite.
