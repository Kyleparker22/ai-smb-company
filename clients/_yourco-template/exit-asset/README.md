# Exit-asset diligence pack — template

**Spec:** `offerings/exit-asset-os/SPEC.md` (frontier #3). Build trigger for the compiled dossier: **first mature engagement (~6 months live)** — but this skeleton clones with the template on day one, on purpose.

## The honest premise of this folder
A diligence pack is only worth showing if it's a **record, not a reconstruction**. This skeleton exists so the pack **fills over the life of the engagement** — each section names the artifact that feeds it, and those artifacts are being produced anyway (handbooks, eval history, autonomy-tier promotions, integration docs, cost ledger). At sale time the pack is **generated** from what already exists; nothing is written backward from memory. A thin ledger dressed as a dossier is narrative — the incumbent product we exist to be distinct from (spec §8: **no dossier without a record**).

What that means in practice:
- **Do not "complete" this folder early.** A slot that has no artifact yet stays `[[not yet — feeds from …]]`. Empty slots are honest; backfilled ones aren't.
- The quarterly refresh (once the engagement is mature) is aggregation + render over existing artifacts — hours, not a project.
- Understudied roles (#7), the eval ledger, and autonomy-matrix history are the **evidence exhibits** — this pack is the frame around them.

## Hard lines (spec §5/§8 — non-negotiable on any surface)
- **Not appraisers, brokers, or advisors** — yourco documents and operates; it never values a business, brokers a sale, or advises on a transaction. No personalized financial/investment advice, ever (house prohibition).
- **No valuation claims or multiple promises.** Any industry-range figure quoted anywhere is third-party, sourced, dated (12–18-month freshness), labeled illustrative.
- **No success fees tied to sale price.**
- **Release only on the client's written instruction**, to named recipients, logged. Buyer console access = read-only, time-boxed, audit-logged, NDA'd (gate #1 suite). Never yourco marketing material without the standard client-approval path.
- **Assignability is engineered on day one:** the assignability + client-owned-artifact clauses ride counsel gate #1 with the engagement agreement — value exists only if they predate the exit by years.
