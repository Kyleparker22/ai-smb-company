# Reed — Video Production SOP (Higgsfield → Descript)

**Owner:** Reed · **Established:** 2026-06-09 (first run: landscaping intake demo, the Founder-approved)
**Stack lock:** `/decisions/2026-06-09_Reed-higgsfield-animation-stack.md` (supersedes Canva for animation)
**Methodology:** animated + conceptual — show the agent's workflow (problem → agent at work → outcomes), not real humans or literal product UI. Credibility gate: "animated faithfully — every workflow shown represents what YourCo will actually build."

## When this runs
Reilly (or the Founder) files an asset request per vertical/use-case (`/agents/Reed/requests/`). Email 2 of Reilly's sequence cannot ship without a registered asset.

## Tools
- **Higgsfield** (MCP) — animation engine. Default model **Seedance 2.0** (reference-driven, consistent identity, silent). ~22–25 credits per ~5s 720p clip; ~300 for a full set.
- **Descript** (MCP) — VO generation + multi-clip assembly + captions + publish.
- **Canva Pro** — brand kit + (fallback) GIF export.
- **Loom** — hosting (optional; Descript share page also works).
- Brand: Cream `#F4EFE6`, Midnight Indigo `#161B33`, Brass `#B8965A`, lowercase `yourco`.

## Pipeline (the repeatable steps)
1. **Script + storyboard** — per `/agents/reilly/copy-structure.md` (problem → agent → outcomes arc). the Founder approves the script.
2. **Style lock (gate 1):** generate ONE hero scene in Higgsfield; show the Founder; get the look approved **before** generating the full set (protects credits). Iterate the hero, not the whole set.
3. **Generate the scene set** in Higgsfield at **1× speed** — enough footage (~55–65s of clips) to cover the VO **without slow-motion**. Lock the style across scenes (consistent character + palette).
   - **No on-screen text in generated clips** — AI can't spell. Use icons/bars/abstract placeholders; all real labels/captions are added in post. Decline irrelevant preset suggestions (`declined_preset_id`).
4. **VO script** — calm, professional, consultative tone; ~70–75s; ends on "live in 48 hours from signed agreement." Brand voice; `yourco` = "im-PAR-oh."
5. **Assemble in Descript:** import the clips → `prompt_project_agent` to place clips at 1× under the VO, add captions, add the cream end frame, mute clip audio.
6. **Generate the voice — MANUAL STEP (open automation gap):** Descript's MCP can't render the AI voice. Open the project in the Descript app → select the script → assign a calm male AI voice → set the `yourco` pronunciation → it renders + captions sync. (To automate later: a cloud TTS-render handle — see decision 2026-06-09.)
7. **Publish** via Descript → share URL + MP4. (Re-publish after any edit.)
8. **GIF preview** — 3–5s loop, ≤2MB, of the most arresting beat. *Known limit:* Canva MCP is unreliable for video→GIF; in practice the email preview is generated by Instantly from the clip at send time, or downloaded manually from Descript/Canva.
9. **the Founder final-cut approval (gate 2, hard).** No publish/registration without it.
10. **Register** in `/agents/Reed/_asset_registry.md` (status `published` + URLs) and notify Reilly to drop the link/GIF into Email 2.

## Gates
- **Style approval** before generating the full set (gate 1).
- **the Founder final-cut approval** before publish + registry (gate 2).
- Animated-only (no real-agent capture, no live B-roll). Captions never baked by the generator.

## Cost
~300 Higgsfield credits + Descript AI credits per demo. Logged in `/finance/expenses.md`; Atlas/Charles track usage. Confirm plan tiers (Higgsfield Plus, Descript) for accurate burn.

## Reusability
Lock the first vertical's style/character as the reference; the next vertical swaps the vertical-specific problem/workflow/outcome scenes and reuses the brand frame + end frame. Extract into `yourco-template` (Kemba) once 3+ demos run clean.

## Known gap to close
**AI-voice rendering is the one manual step** (step 6). Everything else (animation, assembly, captions, publish) runs through MCPs. Closing it needs a cloud-callable TTS render (hosted ElevenLabs MCP, Descript exposing speaker assignment, or an always-on runtime with TTS API). Tracked in `/agents/Reed/02_build.md` build status.
