# legal-docs — blank forms, not filled-in records

The originals were **never copied**: they held a real EIN, a registered address, and an unsigned
operating agreement. What is here is the *shape* of each, for you to fill.

> ⚠️ **Once you fill these in, this folder becomes the most sensitive in the repo.** Decide
> deliberately whether your repository is private. Never paste these contents into a chat, a public
> page, or a shared doc — transcripts and caches persist.

| File | What it is |
|---|---|
| `business-info.md` | the single source for legal name, EIN, address — every vendor asks for these |
| `EIN-letter-README.md` | where to put the IRS CP-575 and why you must keep it |
| `insurance-plan.md` | the policies to carry and their status |
| `operating-agreement-DRAFT.md` | a placeholder that deliberately provides no template |
| `counsel-review-TEMPLATE.md` | how to record a lawyer's review so the open items are trackable |
| `valuation-worksheet-TEMPLATE.md` | for pricing equity grants |
