## The load-bearing refusals
- **Software never denies a claim.** The wedding dress gets a procedure: verbatim log, the
  recorded fair-claims schedule's arithmetic, a human decision. Missing inputs → the settlement
  refuses rather than freelancing a number.
- **No stain-outcome promises.** "We'll try" is expressible; "it'll come out" is not — the copy
  runs the promise check structurally.
- **The disposal clock.** Nothing disposes before the state clock, and even after it, disposal
  is a human act — the touch-3 reminder offers to hold past it, free.
- **Wholesale disputes start from the recorded, dock-signed counts.**
