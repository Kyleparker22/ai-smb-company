## The load-bearing refusals
- **The measure-twice gate.** Orders carry measurement PAIRS as recorded acts — who, when,
  values. A single reading refuses to release naming the gap; two readings that disagree
  beyond the recorded tolerance refuse citing the tolerance and both values. There is no
  force path — a remake is born from one hurried tape reading.
- **The safety-location rule.** Annealed glass quoted into a recorded hazardous location
  (doors, tub/shower, near-floor, stairs) is refused with the rule cited — we don't sell
  code violations cheaper.
- **The deposit wall.** No recorded deposit, no fabrication release — custom glass has no
  second buyer.
- **The fabricator's date.** Lead-time promises cite the fabricator's recorded date or
  refuse; a lead time from hope is a guess with a customer attached.
- **The board-up reads first.** A smashed storefront is a security event — the crew
  dispatches (R2, logged) before any reply copy exists, and it never queues behind a
  shower quote.

## Honesty rules (from `_kit`)
Costly eval label `breakin_boardup`. The remake rate is counted from the shop's own ledger
(cause codes measure/fab/install/customer) and refuses below the completed-order floor —
never an industry estimate. ROI typed: remakes avoided is a scenario (the lift is the
operator's call), deposit float is cash timing, time saved never joins a revenue headline.
Recovered-this-week is counted from the ledgers. Automation % is counted from the event
log or refused. Sweeps skip demo fixtures. Synthetic data only.

**Nothing is sent.**
