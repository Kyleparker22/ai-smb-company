# Decision: Reilly Copy Structure v2 — commission-breath-removal methodology

**Date:** 2026-06-08
**Owner:** the Founder, advised by Reilly + Luka
**Status:** Locked

## What changed
Reilly's cold-outreach methodology pivots from v1 (ICA — single-question-led, pain-mirror, pricing in Touch 3) to v2 (commission-breath-removal — peer-to-peer, problem-first, paint Nirvana, no pricing in cold).

## Why
YourCo's moat is executive trust to high-trust SMB owners. ICA is a transactional-outbound framework built for SDR volume motion — the exact posture that high-trust buyers find off-putting. Aligning the cold sequence to the same moat we sell (peer consultation, radical honesty, prospect controls pace) is the structural fix.

## The structure (locked)
- **3 emails + 3 SMS, 21 days**
- **Email 1** — poke the bear (2-3 specific problems) + paint Nirvana (operational + financial outcomes)
- **Email 2** — Reed-produced demo video (animated GIF preview embedded → Loom landing page)
- **Email 3** — reframe problems + sharper Nirvana + low-pressure release
- **SMS 1, 2, 3** — reference prior email, include Calendly URL, STOP opt-out

## Sub-decisions resolved
1. **Video embed (Email 2):** animated GIF preview → Loom landing page (industry standard; Loom's email-preview product). Reed's roster gate clarified to allow GIF previews (an image, not an embedded video file).
2. **Video owner:** Reed (Content/Demo). Already in roster, scope already includes demo video. Reilly files an asset request to Reed on every campaign build.
3. **Pricing:** pulled entirely from cold sequence. Pricing appears only on the first call after Calendly booking. If a prospect replies asking for pricing, Reilly's response template routes to Calendly with a 2-variable explanation.
4. **CTAs:** no standalone Calendly or website links in email body. Both live in the Founder's email signature (`yourco · getteamyourco.com · Book 15 min`). SMS body retains one Calendly URL (no signature in SMS).
