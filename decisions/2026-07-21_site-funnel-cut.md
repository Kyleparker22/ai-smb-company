# 2026-07-21 — Staged-site funnel cut (OS-centered, single-door proof)

**Decision:** Cut the staged site's link architecture to a tight audit-led funnel. The spine is Home → How it works → What we build → The audit → Pricing → Book a call; everything else sits behind exactly two doors — `demos.html` (all proof: agents in action, your-first-agent live, production work, + go-deeper strip to try-to-break-it / day-in-the-life / 48h) and `objections.html` (all why-yourco: honest answers, + go-deeper strip to compare / reliability / glass-box / manifesto / eval-gated).

**Why:** the Founder's read (2026-07-21): "the staged website has a lot going on — we want it centered on the audit + AI OS as a package, not one-off agents." Review confirmed the spine pages were already on-message post the 2026-06-18 narrowing, but the footer offered ~18 links that diluted the audit CTA, and four pre-narrowing pages plus the instant-employee surface still carried single-agent framing.

**What changed:**
- `careers.html` → `_parked/` (pre-revenue noise for the buyer); removed from all navs, footers, sitemap. Site = 21 live pages.
- Index footer: 4 columns / ~18 links → 3 columns / 10 links. Subpage footer grid slimmed identically (glass-box, try-to-break-it, manifesto, timeline links removed from global footer — reachable via the two hubs).
- `instant-employee.html` reframed as the OS on-ramp: title/h1 now "see the first agent of your AI OS" / "See your first agent"; demos-hub tab relabeled "Your first agent · live"; body copy "employee" → "agent".
- Employee-era language swept to system framing: `glass-box`, `try-to-break-it` ("Every agent in an yourco OS ships through…"), `day-in-the-life` (closer now bridges to "one agent on every door"), `manifesto` (first-hire-is-the-on-ramp bridge added).
- `objections.html` gained the missing obsolescence Q&A — the buyer-facing model-upgrade dividend (same-day companion to the positioning canonization in `01_company.md`).

**Not changed:** no page content deleted; deep pages stay live and linked from their hub, per the `_parked/` pattern of `2026-06-22_website-dial-back.md`. `hire-config.js` / `snapshot-config.js` untouched.

**Revisit when:** launch gate clears — re-verify the funnel against real analytics; or if a hub page's traffic shows a deep page deserves promotion back to the spine.
