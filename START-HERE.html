yourco.

The whole machine, in one tour.

yourco is a boutique AI-implementation consultancy. The motion is Audit first → a custom AI OS that we build and operate inside the client's business — they buy an outcome and never touch a token, a model, or a server. The company is run by a small number of humans and a roster of 27 AI agents. This page is the front door to the entire operating system; walk it top to bottom.

Read this before anything else

yourco is pre-revenue. Zero signed clients. Everything in this tour is built and staged, and nothing external ships until a legal matter (the launch-gate) clears. Several folders look alike and mean completely different things — get this wrong and you will read a prototype as a product:

REALclients/Actual engagements with actual people. Sample Client is at Proposal — unsigned.
DESCRIBEDofferings/33 specs. Written and argued, never built.
BUILT, UNSOLDPre Build Ideas/76 running prototypes on invented data. No client, no revenue.
FAKE ON PURPOSEplayground/The sandbox. Real code, synthetic data.
DEAD_archive/History only. Never cite it for current state.

How it runs itself — the always-on machine

The runtime (24/7 headless) →
A VPS running the loops on systemd timers with no human — they self-gate, commit and push. Always-on is not auto-send: the approval gate lives in the host's own permissions and denies send, delete and shell outright. There is also a global pause switch (runtime/.paused) that makes every loop a no-op.
runtime/README.md · runtime/run-loop.sh
The internal platform →
The golden template and Atlas, the ops agent — the two things that make client delivery scale — plus a pointer table to everything built since.
03_internal_platform.md
The closed-loop substrate →
learnings/ (patterns each run reads at Step 0 and adjusts to) + decisions/ (settled calls, each carrying a trip-wire that says what would reopen it) + rejections/ (the anti-library — checked before any idea is re-proposed). This is how the OS compounds instead of repeating itself.

The primary growth lever — not one channel among several. Connectors refer, and from R1 they recruit connectors who refer, so it compounds without yourco adding headcount. Every channel and how they connect: proof asset → capture → nurture → call → Audit → build → referral. Targeting is horizontal and warm-first — the sequencing filter is relationship, not industry.
