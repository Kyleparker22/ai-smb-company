# The Frontier Board — build roadmap (adopted 2026-08-06 as "the Frontier Ten", the Founder: "build and implement all 10")

> **29 boarded offerings** (it began as ten on 2026-08-06, reached 18 by 08-08, and kept growing — the name stopped being true twice before it was renamed on 2026-08-24). All specced, sequenced by what reality permits. **The rule that governs this file:** pre-revenue, one founder, $0 cash, launch gated — so "build all 10" means *spec all 10 now, build what needs no client or cash now, and give everything else a named trigger.* Anything here that would displace the Year-0 milestones (first engagement signed-or-dead · collaboration papered · counsel engaged) waits. The plan's failure mode #1 is building instead of selling; this roadmap is written so the Frontier Ten never becomes that.

A re-audit against a tidied-up baseline is worthless, and nothing else on this list needs anything from anyone today.

## Sequencing logic
1. **Now (no client, no cash, no gate needed):** #1 ledger (staged page off real `runtime/autonomy-matrix.md` data), #5 standard (doc), #8 hooks (template design — MUST predate client #2; retrofitting a network across bespoke deployments loses the network).
2. **At first signed client:** #7 understudy (the audit upsell), #4 invoice (first billing cycle), #9 boardroom (month-2 add-on).
3. **At launch (OtherVenture clears):** #1 goes public — launch-day story: "the first AI company with a public report card."
4. **Counsel batch:** #6 protocol rides the existing one-engagement-across-gates counsel package.
5. **Compounding era:** #2 (demo-tenant polish), #3 (first renewal conversations), #10 (regional density).

## Interlocks (why these ten are one system, not ten bets)
Trust Ledger (#1) is the proof *surface* → Immune System (#8) is the proof *substance* → Self-Proving Invoice (#4) and Interviewable Employee (#2) are per-client windows onto the same ledger → Understudy (#7) and Boardroom (#9) are the wedges that create clients → Exit-Asset (#3) is the endgame framing of everything above → Mesh (#10) is where Compound goes when the flywheel is actually spinning. The Standard (#5) names the rules the whole stack plays by, in public, first.
