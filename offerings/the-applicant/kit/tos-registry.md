## Do-not-touch list (standing, not pending review)

- Any board whose terms prohibit automated or non-human applicants: excluded on discovery, logged above as PROHIBITED.
- Applicant-pool data, other candidates' materials, or any board data beyond the postings we answer (SPEC §8: no harvesting).
- Any board requiring identity attestation the disclosure would falsify (e.g. "I certify I am a person"): automatic PROHIBITED.

## How a row gets to REVIEWED

1. Ray reads the board's current ToS + acceptable-use + any applicant certification language.
2. Outcome recorded here with date and the specific clauses relied on.
3. Ambiguity = escalate to the gate-#1 counsel batch; the row stays UNREVIEWED until the answer comes back.
4. Format check (disclosure at line one, résumé header intact) run on a real posting preview before the row is marked usable.
5. Rows re-verify on a cadence Ray sets (ToS change without notice; a stale review is treated as UNREVIEWED).
